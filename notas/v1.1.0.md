Falcon Engine 1.1.0 incluye una academia completa de Blueprints, dos mapas shooter 3D y un gestor con apoyo al proyecto y actualizaciones de GitHub.

Falcon Engine 1.1.0 includes a complete Blueprint academy, two 3D shooter maps, project support and GitHub updates in the project manager.

## Added
- **Academia de Blueprints / Blueprint Academy:** 63 laboratorios, uno por cada bloque actual, incluidos funciones, señales, entrada, variables, audio y escenas. Ejemplos ejecutables, pines documentados, comentarios y ejercicios en `GUIA_BLUEPRINTS.md`.
- **Shooter en tercera persona / Third-person shooter:** base abierta de 76 × 76 m, almacenes, flancos, coberturas y seis enemigos.
- **Shooter CQB en primera persona / First-person CQB shooter:** recinto de 32 × 44 m con pasillos, salas, puertas y seis enemigos. Ambas plantillas incluyen los dos mapas y `GUIA_SHOOTER.md`.
- **Combate / Combat:** disparos hitscan, trazas, vida, munición limitada, recarga, patrullas, visión bloqueada por paredes, victoria y derrota. Las nuevas API Águila `disparar_rayo`, `ve_a` y `perseguir` permiten modificar los ejemplos. La IA no calcula rutas alrededor de obstáculos.
- **Actualizaciones / Updates:** consulta de releases de GitHub con SemVer, notas agrupadas, descarga con progreso y comprobación de integridad mediante electron-updater para los nuevos paquetes NSIS y AppImage.
- **Apoyo en Patreon / Patreon support:** botón y selección de membresías en el gestor de proyectos.

## Changed
- **Distribución / Distribution:** instalador Windows x64 y AppImages Linux x64/ARM64, con metadatos de actualización y `SHA256SUMS.txt`. La release solo se publica cuando las tres compilaciones y sus verificaciones han terminado.
- **Licencia / License:** la distribución actual incluye la licencia propietaria del proyecto y los avisos de componentes externos; consulta `LICENSE` y `THIRD_PARTY_NOTICES.md`. Las licencias de versiones anteriores se mantienen para esas versiones.

## Fixed
- **Cobertura / Cover:** las paredes detienen disparos y visión; se comprueba también el trayecto desde el personaje para impedir disparar a través de coberturas cercanas en tercera persona.
- **Plantillas / Templates:** la galería muestra todas las plantillas incluso cuando no disponen de una ilustración específica.

## Installation / Instalación
- **Windows x64:** descarga y ejecuta `Falcon-Engine-1.1.0-win-x64.exe`.
- **Linux x64:** descarga `Falcon-Engine-1.1.0-linux-x86_64.AppImage`, dale permiso de ejecución y ábrela.
- **Linux ARM64:** utiliza `Falcon-Engine-1.1.0-linux-arm64.AppImage`.
- Los paquetes portátiles de v0.1.0 requieren instalar esta versión manualmente. El sistema de actualización se incluye en estos nuevos paquetes. / Old v0.1.0 portable packages require a manual installation of this version; the updater ships in these new packages.
- Los binarios de esta release no tienen firma de editor Windows. Los metadatos SHA-512 y SHA256SUMS permiten verificar integridad; no equivalen a una firma de identidad. / Windows binaries are unsigned; checksums verify integrity, not publisher identity.
- Abre **Gestor → Plantillas**, crea un proyecto y pulsa **F5**. En los shooters, **E** inicia el combate; **R** recarga, **V** cambia la vista y **H** alterna la ayuda.
