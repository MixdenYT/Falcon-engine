Corrección del instalador de Falcon Engine 1.1.0. / Fix for the Falcon Engine 1.1.0 installer.

## Fixed
- **Todas las plantillas:** el instalador omitía la biblioteca `three/examples/jsm`, necesaria para cargar vistas del editor, modelos, controles y efectos. El paquete incluye ahora los módulos completos. / The installer excluded Three.js runtime addons required by the editor and templates; the full runtime library is now included.
- **Modelos de ejemplo:** se incluye el exportador GLTF utilizado para generar el cofre de las plantillas 3D. / The GLTF exporter used to generate sample models is included.
- **Linux:** se conserva el permiso de ejecución del motor dentro de AppImage. / The engine executable permission is set before building AppImage.

## Changed
- **Verificación del paquete:** se impide generar instaladores si faltan módulos esenciales. / Packaging fails when essential runtime modules are missing.
- **Pruebas antes de publicar:** se instala el NSIS de Windows o se extrae la AppImage de Linux y se ejecutan las 11 plantillas desde ese paquete: creación en disco, lectura de recursos, apertura del editor e inicio del juego con Electron, protocolo e IPC reales. Un fallo bloquea la publicación. / Before publication, each installer is exercised with all 11 templates using the real Electron application, filesystem, protocol and IPC; any failure blocks publication.

## Installation / Instalación
- Si tienes v1.1.0, vuelve al gestor y usa **Buscar actualizaciones**, o descarga el instalador de v1.1.1. / From v1.1.0, use **Buscar actualizaciones** in the project manager or download the v1.1.1 installer.
- No borres tus proyectos. Los que ya se crearon se pueden volver a abrir con la versión corregida. / Keep your projects; existing projects can be reopened with the corrected version.
- Windows x64: `Falcon-Engine-1.1.1-win-x64.exe`.
- Linux x64: `Falcon-Engine-1.1.1-linux-x86_64.AppImage`.
- Linux ARM64: `Falcon-Engine-1.1.1-linux-arm64.AppImage`.
- Los binarios de Windows no tienen firma de editor. Se incluyen metadatos SHA-512 y SHA256SUMS.txt para comprobar integridad. / Windows binaries are unsigned; SHA-512 metadata and SHA256SUMS.txt verify integrity.
