# Falcon Engine 1.2.0 — Umbral CQB

Entrega de prueba para Windows. Este trabajo no publica una release automáticamente.

- La plantilla de primera persona pasa a ser un recorrido CQB corto: acceso, oficinas, archivo y sala de control; tres contactos y un terminal final.
- Dos personajes originales de Meshy, PBR, rig independiente de 24 huesos y siete clips por personaje. El operador se reutiliza para los brazos y el enemigo para las tres instancias. Consumo confirmado: 110 créditos; IDs en `recursos/cqb/procedencia.json`.
- Carabina Kestrel C9, pistola Lynx P8 y arma hostil originales, con puntos de boca, miras, cargador y agarres. IK adapta las palmas al arma; la recarga mueve el cargador y la mano de apoyo.
- WASD, Alt para paso lento, Shift para avance rápido, Ctrl para agacharse, Q/E para inclinarse, clic derecho para miras, clic izquierdo o J por disparo, R para recargar, 1/2/T para armas y F para puertas/objetos. H muestra ayuda, L cambia español/inglés, [/] ajusta sensibilidad, Esc suelta el ratón y P/F7 pausa.
- Munición, salud, cadencia, inventarios, recargas, reacción enemiga, puertas y victoria viven en Blueprints editables que compilan y ejecutan Águila. El motor aporta colisión, rayos, animación y navegación A*.
- La IA combina cono de visión, oclusión, audición, memoria, patrulla y posiciones de cobertura comprobadas con rayos. Las paredes, puertas y cuerpos bloquean el movimiento; las paredes y la cobertura cercana bloquean disparos.
- Cuatro bloques generales nuevos: Leer propiedad, Cambiar propiedad, Consultar método y Ejecutar método. Academia cubre los 67 bloques del catálogo.
- Se verifica el contenido del paquete mediante SHA-256. Los GLB se almacenan por bloques en Git y se reconstruyen sin cambios antes de probar o compilar; el instalador contiene los GLB completos.
- `herramientas/probar-instalado.cjs` instala el NSIS real, crea las once plantillas, abre y ejecuta cada una, prueba CQB hasta la victoria y vuelve a abrir juego y editor. Conserva resultados JSON, capturas reales y el ZIP del proyecto generado.

## Alcance

Inspiración en precisión y controles tácticos; no incluye recursos de Ready or Not. Esta plantilla usa el motor propio con colisión por cajas, navegación A* en una cuadrícula de 50 cm y coberturas colocadas por el autor. No incluye simulación balística, penetración, cooperación ni sistemas de arresto.

## English

Windows test delivery. The first-person template is now a short, complete CQB route with three hostiles, working doors and a final terminal. Two original Meshy characters share PBR styling, independent 24-bone rigs and seven clips each. Confirmed Meshy consumption: 110 credits. Weapons, surfaces and WAV effects are original Falcon resources.

Editable Blueprints execute real Águila for ammunition, health, timers, weapon inventories, reloads, AI decisions, doors and victory. Native code provides rays, collision, animation, hand IK and A* navigation. H opens controls and L switches the HUD/help language.

Installer verification creates all eleven templates from the installed package, opens and starts each, completes the CQB route using keyboard/mouse inputs, closes and reopens the project and preserves actual screenshots, JSON results and a ZIP of the generated project. Publication is disabled by default.
