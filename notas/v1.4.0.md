# Falcon Engine 1.4.0 — Powered by Ara

Falcon Engine 1.4.0 lleva el núcleo del motor y los Blueprints a **Ara**, refuerza la seguridad del editor y de los juegos, y se publica por primera vez para **Windows arm64**. Es una versión del canal **Pruebas**.

Falcon Engine 1.4.0 moves the engine core and Blueprints to **Ara**, hardens the editor and games, and ships natively for **Windows arm64** for the first time. This is a **Pruebas** (testing) channel release.

## Added
- **Núcleo del motor en Ara / Engine core in Ara:** la física 2D, las transformaciones, las cajas y los contactos 2D, y el núcleo táctico 3D (rayos contra cajas y rutas A*) están escritos en Ara y precompilados a WebAssembly. Solo se envía al núcleo lo que cambió en cada fotograma. / 2D physics, transforms, boxes, 2D contacts and the 3D tactical core (box raycasts and A* paths) are written in Ara and precompiled to WebAssembly.
- **Blueprints compilados por Ara / Blueprints compiled by Ara:** el compilador de Blueprints está escrito en Ara y es el único. / The Blueprint compiler is now written in Ara and is the only one.
- **Runtime nativo de ejemplo / Native runtime example:** `examples/native-2d/` es un `.exe` de Ara con ventana Win32 y OpenGL que juega el nivel «plataformas» con la misma física, los mismos scripts y los mismos Blueprints que Falcon, con resultados idénticos bit a bit. Es un ejemplo, no un objetivo de exportación. / A Win32 + OpenGL Ara executable that plays the «plataformas» level bit-for-bit like Falcon. It is an example, not an export target.
- **Windows arm64:** instalador nativo para portátiles Windows ARM (Snapdragon), con sus propias actualizaciones. Exportar juego ofrece también **Windows arm64**. / Native installer for Windows on ARM with its own updates; game export also offers Windows arm64.

## Changed
- **Arquitectura en cada archivo / Architecture in every file:** los instaladores llevan `x86_64` o `arm64` en el nombre, y Exportar juego muestra Windows x86_64, Windows arm64, Linux x86_64 y Linux arm64. / Installers name `x86_64` or `arm64` explicitly; the export dialog does too.
- **Electron 44.11.5** (desde 44.9.0).
- Ara al día: compilador web y runtime de Ara más pequeños (el runtime, escrito ahora en Ara, pasa de 96 KB a 88 KB). / Smaller Ara web compiler and runtime (now written in Ara, 96 KB → 88 KB).
- Al cargar un proyecto se descartan las propiedades de nodo con un tipo incorrecto. / Node properties with a wrong type are dropped on load.

## Fixed
- Exportar al destino por defecto (`<proyecto>/exportado`) metía los `.ara` exportados dentro del juego y no arrancaba. / Exporting to the default folder broke the game.
- Los juegos exportados no arrancaban por faltar archivos de la API de Ara. / Exported games failed to start because Ara API files were missing.
- Plantilla «plataformas»: el enemigo ya no empieza dentro del suelo, no cae al hueco ni vibra contra la roca; patrulla de verdad. / The platformer enemy now patrols correctly.

## Security
- Todas las ventanas usan `sandbox: true`, y un gestor de permisos niega cámara, micrófono, ubicación y avisos. / All windows are sandboxed; camera, microphone, location and notifications are denied.
- El IPC queda limitado a las carpetas permitidas para cada ventana, y el juego usa un preload reducido de solo lectura. / IPC is limited to allowed folders per window; games get a reduced read-only preload.
- Las CSP del editor, el gestor y el juego ya no permiten `'unsafe-inline'` en `script-src`. / CSPs no longer allow inline scripts.
- Corregidos un XSS persistente con datos del proyecto y un path traversal en `falcon://app`. / Fixed a stored XSS via project data and a path traversal in `falcon://app`.
- Electron 44.11.5 corrige un aviso de gravedad alta (GHSA-jr5w-w6x2-84p9). / Electron 44.11.5 fixes a high-severity advisory.

## Compatibility / Compatibilidad
- Los proyectos de versiones anteriores se abren igual. / Older projects open as before.
- Una instalación x86_64 se actualiza siempre a x86_64 y una arm64 a arm64. Falcon 1.3.0 (Windows x64) recibe la 1.4.0 x86_64 si usa el canal **Pruebas**. / x86_64 installs update to x86_64 and arm64 to arm64; 1.3.0 receives 1.4.0 x86_64 on the Pruebas channel.
- En un equipo Windows ARM con la versión x86_64 instalada, desinstálala e instala la arm64 para pasar a nativo. / On Windows on ARM, reinstall with the arm64 installer to go native.

## Installation / Instalación
- Esta versión solo aparece en **Buscar actualizaciones** con el canal **Pruebas** activado en el gestor; también puedes descargar el instalador. / Only offered to the Pruebas channel; or download the installer.
- **Windows x86_64:** `Falcon-Engine-1.4.0-windows-x86_64.exe`.
- **Windows arm64:** `Falcon-Engine-1.4.0-windows-arm64.exe`.
- **Linux x86_64:** `Falcon-Engine-1.4.0-linux-x86_64.AppImage` (dale permiso de ejecución / make it executable).
- **Linux arm64:** `Falcon-Engine-1.4.0-linux-arm64.AppImage`.
- Los binarios de Windows no tienen firma de editor. Se incluyen metadatos SHA-512 y `SHA256SUMS.txt` para comprobar la integridad. / Windows binaries are unsigned; SHA-512 metadata and `SHA256SUMS.txt` verify integrity.
